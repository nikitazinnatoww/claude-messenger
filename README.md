# Talk — Claude-styled Messenger UI

Элегантный веб-мессенджер в крафтовом визуальном стиле Claude:
- Теплая пергаментная палитра слоновой кости (`#FAF9F5`), нейтральные границы и фирменный терракотовый акцент (`#D97757`)
- Типографика: антиквенный редакционный шрифт Newsreader для заголовков + Inter для сообщений
- Парящее поле быстрого ввода (Prompt Box) с выбором собеседника чипами и терракотовой кнопкой отправки (`↑`)
- Полнофункциональная мобильная версия + полноценная версия под ПК
- Встроенный переключатель между мобильной и десктопной версией внизу экрана
- Светлая и темная тема с сохранением в localStorage
- Живые компоненты: аудиоплеер с анимированной звуковой волной, карточка Figma-прототипа, PDF-вложения, статусы доставки (`✓✓`)

## Запуск

Просто откройте `index.html` в любом современном браузере.
